Download extension

Release 5.1.2 · ZIP

  1. Download & extract

    Download the ZIP and extract it into a permanent folder.

  2. Open extensions

    Go to chrome://extensions or edge://extensions in your browser.

  3. Load the folder

    Enable Developer mode, choose Load unpacked, and select the folder containing manifest.json.

  4. Refresh your chat

    Refresh a ChatGPT or Claude web tab. Look for the language bubble near the top-right corner.

Already installed? Replace the files in your extension folder, click Reload on its card, and refresh your chat tabs.

GOOD TO KNOW

A few honest
answers.

Will it reduce my token usage?

Translation can change the token count, but savings depend on the text and the model. Token Saver does not measure tokens or guarantee a percentage. Compare both versions using the same model’s tokenizer to evaluate your own messages.

Which websites does it work on?

The extension is configured for chatgpt.com, chat.openai.com, claude.ai, and Claude subdomains. It is a browser extension, with no desktop-app integration. Website changes can affect compatibility.

Does it translate every message?

No. It uses a non-ASCII character heuristic to decide which drafts to translate. Very short messages and text written mainly with ASCII letters can pass through. The README explains the exact limits.

Can I still add a new line?

Yes. Shift+Enter keeps its normal newline behavior. Enter and the recognized send button trigger translation when the extension is enabled.

Does it translate the assistant’s replies?

It translates eligible outgoing drafts. Chat history, attachments, system instructions, and assistant replies are not translated. Ask the assistant explicitly if you want replies in a particular language.

A clear note about your text.

When enabled, eligible drafts are sent to Google’s translation service before the chat website. Code and link placeholders are formatting aids, not a privacy filter. Turn translation off for text you don’t want to send to that service.
